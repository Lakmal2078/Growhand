# Deployment

Growhand is a Vite application. Production builds are generated into `dist/`.

## Build

```bash
npm ci
npm run lint
npm test
npm run build
```

Deploy the contents of `dist/` to a static hosting provider.

## Camera requirements

Camera access requires a secure context. Production deployments must use HTTPS. `localhost` is suitable for local development.

## Hosting checklist

- Serve `dist/` as the site root.
- Enable HTTPS.
- Preserve the SPA/static asset paths generated by Vite.
- Verify camera permission behavior on desktop and mobile browsers.
- Verify the canonical URL and Open Graph metadata in `index.html` match the deployed domain.
- Review response security headers at the hosting layer.

## Production verification

After deployment, verify:

1. The landing page loads without console errors.
2. Camera Studio requests permission only after user interaction.
3. Start/Stop camera releases media tracks.
4. Hand tracking works on supported browsers.
5. Contact and external profile links work.
6. Theme preference persists after reload.
