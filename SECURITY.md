# Security Policy

## Supported versions

The default branch is the actively maintained version of Growhand.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, contact the project maintainer privately through the contact information published on the project website or GitHub profile. Include:

- A clear description of the issue
- Steps to reproduce it
- The affected file or component
- Any relevant impact or proof of concept

Please avoid including credentials, personal data, or other secrets in reports.

## Privacy notes

Growhand requests camera access only when the Camera Studio is started. The application is designed to process camera frames in the browser rather than upload them to an application backend.
